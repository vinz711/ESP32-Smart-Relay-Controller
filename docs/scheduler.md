# Scheduler

The scheduler is designed to support relay automation without hard-coding a specific application.

Planned/implemented scheduling concepts include:

- Start and stop times
- Multiple schedules per relay
- Weekday selection
- AUTO and MANUAL modes
- Manual control behavior while a schedule is active
- Emergency OFF override

Application profiles can use the same scheduler for lights, pumps, fans, heaters, valves, or other compatible relay loads.
