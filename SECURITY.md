# Security

## Reporting a Security Issue

Please do not publish sensitive security issues, credentials, or private device information in a public issue.

For issues involving exposed credentials or other sensitive information, remove the secret from the device and repository immediately and report the issue privately to the repository owner.

## Device Security

This project provides a local web interface for controlling physical devices. Users should:

- Use a trusted Wi-Fi network.
- Protect access to the controller.
- Never commit Wi-Fi passwords or API credentials.
- Avoid exposing the controller directly to the public internet.
- Use appropriate network isolation where practical.
